# Intent to Done Setup

사용자가 선택한 모델과 추론 정책을 현재 도구의 실제 지원 설정으로 반영한다. 이 스킬은 계정의 이용 한도를 늘리거나 다른 공급자의 구독을 연결하지 않는다.

## 1. 현재 상태 확인

현재 도구와 설치 버전, 실제로 확인할 수 있는 이용 가능 모델, 관련 기본값과 역할 override를 읽는다. 인증 파일과 비밀 값, 관련 없는 전체 설정을 출력하지 않는다. 모델 목록을 확인할 수 없으면 사용자가 현재 모델 선택기에서 확인한 값이나 부모 상속을 사용한다. 이름을 추측해 저장하지 않는다.

현재 값, 요청 값, 확인 가능한 실제 적용값을 구분한다. 모델명이 같아도 Codex와 Claude Code의 추론 수준이 같은 계산량을 뜻한다고 설명하지 않는다. [플랫폼 설정](references/platform-settings.md)을 현재 도구 부분만 읽는다.

## 2. 선택표와 질문

다음 역할을 보여주고 필요한 항목만 질문한다. 기존 선택은 보존한다. 사용자가 이미 값을 지정했다면 같은 선택을 다시 묻지 않는다.

| 역할 | 설정 방식 |
| --- | --- |
| 주 담당 | 현재 세션 선택을 사용. 세션 변경 수단이 지원되고 사용자가 요청한 경우에만 변경. |
| how, why, teach | 기본 주 담당 실행. 기능별 보조 생성과 자동 추론 상향 없음. 별도 보조 실행을 요청한 경우에만 해당 역할 선택. |
| 구현 보조 | 필요한 경우에만 실행. 모델과 추론을 실제 지원 값으로 선택하거나 부모 상속. |
| 독립 검증 | 별도 컨텍스트. 모델과 추론 선택 또는 부모 상속. 다른 모델을 필수로 요구하지 않음. |
| 동시 실행 | 주 담당 포함 최대 3개, 보조 최대 2개. 현재 요청이 모델 설정뿐이면 이 상한을 변경하지 않음. |

미설정 모델과 추론은 부모 상속을 시작 정책으로 사용한다. 낮은 비용을 보장하는 정책은 아니다. 필요하면 절약형, 기본형, 깊은 검토형의 장단점을 설명하되 확인하지 않은 모델과 수준의 조합을 자동 배정하지 않는다. 역할별 추론 상향과 모델 대체를 허용할지도 명시적으로 선택받는다.

## 3. 변경 반영

선택표를 구체화한 뒤 요청한 범위만 변경한다. 사용자가 현재 상태 확인만 요청했다면 쓰지 않는다. 전역과 프로젝트 중 적용 범위가 미정이면 먼저 확인한다. 현재 도구 하나만 설정한다고 다른 도구까지 변경하지 않는다.

사용자의 설정 변경 요청과 선택이 명확하면 불필요한 재확인을 추가하지 않는다. 실행 환경의 쓰기 권한과 승인이 필요한 경우 실제 대상과 변경 내용을 보여주고 그 절차를 따른다. 기존 설정과 사용자의 다른 에이전트 정의를 보존한다.

두 도구를 함께 설정할 때는 각 도구의 이용 가능한 모델을 따로 확인한다. 공통 선택을 각 도구의 native 설정에 반영하며 공통 문서만 저장하고 적용 완료라고 하지 않는다. 모델명과 추론을 스킬 본문에 하드코딩하지 않는다.

## 4. 확인과 보고

변경 파일과 선택값, 적용 범위, 검사한 항목과 실제 적용값 또는 미확인 사유를 짧게 보고한다. 지원하지 않는 선택은 알리고 임의로 다른 모델이나 추가 과금 수단으로 대체하지 않는다. 기존 상속을 유지할 수 있으면 선택지로 제시한다.

설정 문법과 도구의 인식을 확인한다. 실제 적용을 확인하지 못하면 완료를 과장하지 않는다. 한도와 환경 문제로 중단하면 선택표와 남은 확인을 보존하고 추가 API 과금과 크레딧으로 자동 전환하지 않는다.
