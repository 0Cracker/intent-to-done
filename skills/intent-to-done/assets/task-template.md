- 원래 요청:
- 프로젝트 루트와 작업 문서 경로:
- 기록 모드: 문서
- 현재 단계: 0. 현황
- 상태: 조사 중
- 사양 버전과 승인 상태: 미작성, 미승인
- 자동 진행과 결정권 위임: 명시된 범위 없음, 기본 단계별 확인
- 코드 상태:
- 미결, 보류와 중단 이유:
- 다음 행동:

## 문서 위치와 상태

| 역할 | 정본 위치 | 현재 상태 |
| --- | --- | --- |
| 의도 | intent.md, 생성 후 상대 링크로 변경 | 미작성 |
| 사양 | SDD.md, 생성 후 상대 링크로 변경 | 미작성 |
| 구현 계획과 실행 | implementation.md, 생성 후 상대 링크로 변경 | 미작성 |

문서는 해당 단계에서 만들고 기존 정본이 있으면 연결한다. 아래 단계 요약에는 상태와 링크만 두며 계약, 작업 순서와 실행 결과를 중복 기록하지 않는다.
