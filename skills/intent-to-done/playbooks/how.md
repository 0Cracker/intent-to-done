# How

현재 코드의 동작을 확인한다. 기본은 주 담당 실행이며 탐색자와 설명자의 별도 호출은 요구하지 않는다.

1. 질문 대상과 변경 흐름을 좁힌다. 모호하면 잠정 범위를 밝히고 제품 선택만 묻는다.
2. 진입점부터 입력, 상태 소유자, 변환, 소비자까지 실제 호출을 추적한다. 관련 호출자와 경계, 실패 경로도 확인한다.
3. 관련 테스트와 설정을 대조한다. 코드에서 본 것과 실행으로 확인한 것을 구분한다.
4. 질문 수준에 맞춰 동작, 위치와 주의점을 설명한다. 함수 목록만 나열하지 않는다.

짧은 질문은 짧게 답한다. 구성요소 간 연결이 핵심일 때만 작은 흐름도를 쓴다. 읽지 않은 경로와 미실행 동작은 미확인으로 표시한다. 결과는 다음 사양과 구현에 재사용하고 같은 코드를 기능별로 재탐색하지 않는다.
