# How

현재 코드가 어떻게 작동하는지 확인한다. 기본은 주 담당 실행이다. 이 문서가 탐색자와 설명자의 별도 호출을 요구하지 않는다.

1. 질문의 대상과 변경할 흐름을 좁힌다. 해석이 모호하면 잠정 범위를 밝히고 제품 선택이 필요한 부분만 묻는다.
2. 진입점부터 입력, 상태 소유자, 변환, 소비자까지 실제 호출을 추적한다. 관련 호출자와 경계, 실패 경로도 확인한다.
3. 설명에 필요한 테스트와 설정을 대조한다. 코드에서 보인 것과 실행으로 확인한 것을 구분한다.
4. 사용자가 묻는 수준에 맞춰 동작과 위치, 주의점을 설명한다. 세부 함수 목록을 설명의 전부로 삼지 않는다.

짧은 질문은 짧게 답한다. 여러 구성요소의 연결이 핵심일 때만 작은 흐름도를 쓴다. 읽지 않은 경로와 실행하지 않은 동작은 미확인으로 표시한다. 산출물은 다음 사양이나 구현에 재사용하고 같은 코드를 기능별로 재탐색하지 않는다.
