# Claude Code 실행 지침

현재 클라이언트의 도구와 적용 지침이 우선이다. 지원 여부를 확인하지 않은 Claude 전용 필드를 Codex에 그대로 사용하지 않는다.

## 실행

- 주 담당은 스킬과 필요한 플레이북을 읽고 인터뷰와 단계를 진행한다. how, why, teach를 subagent 실행 문맥으로 강제하지 않는다.
- 독립 검증에는 전체 대화를 상속하는 fork보다 필요한 자료만 전달한 새 subagent를 사용한다. 도구와 버전에서 동작을 확인한다.
- 검증자의 도구는 실행에 필요한 범위로 정하고 제품 코드 수정과 재위임을 금지한다. 지시만으로 운영체제 수준의 쓰기 제한을 보장한다고 설명하지 않는다.
- 보조는 원래 목표와 확정 계약, 코드 상태, 소유 범위와 검증 기준을 전달받는다. 자동으로 모든 스킬과 출력 스타일을 상속한다고 가정하지 않는다. 필요한 공통 규칙을 명시한다.
- 주 담당 포함 동시 3개를 직접 관리한다. fork와 재개, 다른 에이전트 기능까지 포함해 세며 상한을 피하려고 다른 기능으로 호출하지 않는다.

## 설정과 보고

역할별 모델은 custom subagent의 model, 추론 수준은 effort로 설정할 수 있다. 선택한 모델과 설치 버전에서 지원되는 값만 쓴다. CLAUDE_CODE_SUBAGENT_MODEL 등 전역 환경 설정과 단발 인자, 역할 정의 사이 우선순위를 최신 [공식 문서](https://code.claude.com/docs/en/sub-agents)로 확인한다.

CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS는 보조 상한 2개를 설정하는 수단이지만 일부 기능과 재개 등에 예외가 있다. 모든 호출의 전체 상한을 이 설정만으로 보장한다고 설명하지 않는다.

보고 규칙은 이 스킬이 제공한다. Claude Code의 별도 output style을 필수로 설치하지 않는다. 사용자가 요청해 스타일을 추가한다면 코딩 지침을 보존하는 keep-coding-instructions 옵션과 현재 클라이언트 지원을 확인한다. 스타일이 일반 subagent의 보고까지 자동 변경한다고 가정하지 않는다.

## 기본 적용

개인 스킬은 실제 지원되는 설치 경로를 확인한다. 사용자 요청으로 전역 기본 적용을 연결할 때는 CLAUDE.md에 짧은 호출 규칙을 기존 내용과 합친다. 스킬 실행을 이유로 기존 전역 설정과 권한 모드를 덮어쓰지 않는다. 세부 사항은 [스킬 문서](https://code.claude.com/docs/en/skills)를 확인한다.
