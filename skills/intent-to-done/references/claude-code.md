# Claude Code 실행 지침

현재 클라이언트의 도구와 지침이 우선이다. 지원을 확인하지 않은 Claude 전용 필드는 Codex에 쓰지 않는다.

## 실행

- 주 담당이 스킬과 해당 플레이북을 읽고 인터뷰와 단계를 진행한다. how, why, teach의 subagent 실행을 강제하지 않는다.
- 독립 검증은 전체 대화를 상속한 fork보다 필요한 자료만 받은 새 subagent를 쓴다. 도구와 버전에서 동작을 확인한다.
- 검증 도구는 실행에 필요한 범위로 정하고 제품 코드 수정과 재위임을 금지한다. 지시만으로 운영체제 수준의 쓰기 제한을 보장하지 않는다.
- 보조에 원래 목표, 확정 계약, 코드 상태, 소유 범위와 검증 기준을 전달한다. 모든 스킬과 출력 스타일의 자동 상속을 가정하지 말고 필요한 공통 규칙을 명시한다.
- 주 담당 포함 동시 3개를 직접 관리한다. fork, 재개와 다른 에이전트 기능도 포함하며 다른 기능으로 상한을 우회하지 않는다.

## 설정과 보고

역할별 모델은 custom subagent의 model, 추론은 effort로 설정할 수 있다. 선택 모델과 설치 버전의 지원 값만 쓴다. CLAUDE_CODE_SUBAGENT_MODEL 등 전역 환경 설정, 단발 인자와 역할 정의의 우선순위는 최신 [공식 문서](https://code.claude.com/docs/en/sub-agents)로 확인한다.

CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS는 보조 상한 2개를 설정하지만 일부 기능과 재개 등에 예외가 있다. 이 설정만으로 모든 호출의 전체 상한을 보장하지 않는다.

보고 규칙은 이 스킬이 제공하며 별도 output style 설치는 필수가 아니다. 스타일 추가를 요청받으면 코딩 지침을 보존하는 keep-coding-instructions 옵션과 클라이언트 지원을 확인한다. 일반 subagent 보고의 자동 변경을 가정하지 않는다.

## 기본 적용

개인 스킬은 실제 지원 설치 경로를 확인한다. 전역 기본 적용을 요청받으면 CLAUDE.md의 기존 내용에 짧은 호출 규칙을 합친다. 스킬 실행만으로 전역 설정과 권한 모드를 덮어쓰지 않는다. 세부 사항은 [스킬 문서](https://code.claude.com/docs/en/skills)를 확인한다.
