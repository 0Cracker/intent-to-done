# Codex 실행 지침

현재 환경의 도구와 지침이 우선이다. 없는 명령과 모델을 추측하지 않는다. 이 파일의 일반 설정이 현재 환경의 지원을 보장하지 않는다.

## 실행

- 현재 환경의 파일, 명령과 질문 도구를 쓴다. 질문이 필요한 단계는 실제 답을 기다린다.
- 스킬의 해당 플레이북을 파일 읽기로 로드한다. how, why, teach는 기본적으로 주 담당이 실행한다.
- 독립 검증은 fresh context를 쓴다. collaboration 도구가 fork_turns를 지원하면 none으로 호출하고 원래 요청, 확정 사양, 대상 코드와 실행 환경을 별도로 전달한다. 다른 인터페이스는 같은 목적의 지원 기능을 확인한다.
- 모델과 추론은 현재 사용 가능한 값만 쓰고 없는 값을 반복 시도하지 않는다. 역할 지정이 별도 권한과 읽기 전용 sandbox를 만들지는 않는다. 제품 코드 수정 금지를 지시하고 가능한 도구 제한을 쓴다.
- 새 컨텍스트가 불가하면 같은 세션의 재검토를 독립 검증으로 표시하지 않고 완료를 보류한다.

## 설정을 해석할 때

공식 문서의 전체 기본값은 config.toml의 agents.default_subagent_model과 agents.default_subagent_reasoning_effort다. 사용자 정의 에이전트 파일의 model과 model_reasoning_effort도 지원된다. 정의 파일의 값은 기본값과 단발 요청의 우선순위에 영향을 주므로 실제 적용을 확인한다.

agents.max_concurrent_threads_per_session은 주 담당 제외 상한이다. 보조 2개와 전체 동시 3개 규칙을 함께 관리하며 전역 설정을 자동 변경하지 않는다.

설정 확인 시 최신 [공식 문서](https://learn.chatgpt.com/docs/agent-configuration/subagents)와 설치된 클라이언트를 대조한다. 무관한 인증과 비밀 값은 출력하지 않는다.

## 기본 적용

자동 선택은 매번 호출을 보장하지 않는다. 전 프로젝트 기본 적용을 요청받으면 실제 설치 경로를 확인한다. 전역 AGENTS.md의 기존 내용에 “코딩 작업에 intent-to-done을 사용하며, 조사만 요청하면 해당 기능만 수행한다”는 연결 규칙을 합쳐 제안한다. 설치와 전역 지침 편집은 별도 작업이며 다른 프로젝트 규칙을 덮어쓰지 않는다.
